# 图 S1/S2 所用 1842 条曲线：按 DOI 汇总的数据集

`dataset/` 下面直接是 1204 个 DOI 文件夹；DOI 中的 `/` 用 `_` 代替。每个文件夹直接包含该论文参与本轮四簇拟合的原始 CSV、对应的论文原图 PNG，以及原数据中由 Python 提取曲线后生成的 `_replot.png` 图。没有按 `data_all`、`final_data` 或时间轴再分层。

`curve_index.csv` 每行对应一条曲线，记录曲线 ID、Cluster 1–4 编号、原始来源、在本数据集中的 CSV/原图/replot 路径，以及三个文件的 SHA-256。多个曲线可能来自同一论文图，因此共用原图和 replot。两篇 DOI 中分别有一对来源不同但图号同名的图；这些图像带 `__variant_1` 或 `__variant_2` 后缀，索引准确记录每条曲线对应的版本。

CSV 保留原始点列和原横轴单位。`cluster` 列为从 1 开始的拟合簇编号，并非经独立验证的真实类别。

在上一级目录运行 `python3 verify_delivery.py`，可核验本数据集的文件、索引和哈希，并检查它与模型输入的曲线 ID 对应关系。
